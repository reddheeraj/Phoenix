# 🚀 Quick Start

```bash
# 1. Install
pip install -r requirements.txt

# 2. Get API key (free)
# Visit: https://www.api-ninjas.com/

# 3. Set key
export API_NINJAS_KEY="your_key"

# 4. Run
python main.py
```

Select your fitness level, and you'll get:
- Personalized workout plan
- Side quests with exercises
- XP + coin rewards
- Special offers

See `README.md` for details.
